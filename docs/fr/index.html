01 Fonctions

    04 Installation
    
      
    Deux commandes et la pastille apparaît.
    
      
    L'installateur crée un environnement Python privé, télécharge PySide6 et enregistre l'app dans le menu des applications. Rien n'est installé dans le Python du système.
    
    
    

    
    
      
    
        
        
      
    
      
    
    

    
    
      
    
        
    1
    
        
    
          
    Clonez et installez
    
          
    Copie l'app dans ~/.local/share/vigia et crée le lanceur dans
          ~/.local/bin/vigia.
    
          
    $git clone https://github.com/stefanoferrao/vigia.git
$cd vigia && ./install.sh
    
        
    
      
    
      
    
        
    2
    
        
    
          
    Ouvrez VigIA
    
          
    Depuis le terminal ou via le raccourci VigIA du menu des applications.
    
          
    $vigia
    
        
    
      
    
      
    
        
    3
    
        
    
          
    Affichez et masquez avec le raccourci
    
          
    Ctrl+Alt+V affiche/masque (et lance l'app si elle ne tourne pas). Pour le changer, modifiez hotkey dans la config.
    
        
    
      
    
    
    

    
    
      
    
        
    1
    
        
    
          
    Clonez et lancez l'installateur
    
          
    Dans PowerShell, à l'intérieur du dossier cloné. Il crée
          %LOCALAPPDATA%\vigia avec l'environnement et les raccourcis.
    
          
    PS>powershell -ExecutionPolicy Bypass -File .\install.ps1
    
        
    
      
    
      
    
        
    2
    
        
    
          
    Ouvrez depuis le menu Démarrer
    
          
    Cherchez VigIA. Le démarrage automatique utilise la clé
          HKCU\...\Run et peut être désactivé dans le menu.
    
        
    
      
    
    
    

    
    
      
    
      0 sur 0 étapes copiées
    
    

    
    
      
    Données de quota : VigIA lit les chiffres du CLI
        ai-usagebar. Sans lui, la pastille s'ouvre mais reste sans chiffres.
    
      
    Linux: nécessite libxcb-cursor0 (l'installateur prévient et tente de le résoudre via apt, dnf ou pacman).
    
      
    Raccourcis avec Super : le système les intercepte souvent avant l'app — c'est pourquoi le défaut est Ctrl+Alt+V.
    
    
    
  
    

    


    
  
    
    
    
      
    05 Quoi surveiller
    
      
    Chaque fournisseur affiche la limite qui compte pour vous.
    
      
    Par défaut, c'est le plus gros usage. Dans le menu, choisissez la fenêtre de chaque fournisseur — le choix est enregistré et survit aux changements de nom du libellé.
    
    
    
    
    
      
    
        
    
          
          
          
        
    
        
          57%
          Weekly (7d)
        
        
    Choisissez ci-dessus pour voir ce que la pastille afficherait. Dans l'app, il en va de même dans Quoi surveiller.

    07 Configuration
    
      
    Tout dans un seul TOML — composez le vôtre ici.
    
      
    Le menu de l'app écrit dans ce fichier ; les modifications manuelles sont appliquées avec
      vigia --reload. Tout ce que vous avez modifié sur la page s'y trouve déjà.
