Como funciona

Uma linha, sempre à vista.

Ícone do provedor e porcentagem do limite, com espaçamento em três níveis: dentro do item, entre itens e entre o bloco de IA e o de sistema.

Largura estável

Os números ficam alinhados dentro de um slot fixo, então a pílula não dança quando o uso oscila.

Nove encaixes

Topo, meio ou base — à esquerda, no centro ou à direita. Ou arraste livre: a posição fica salva por monitor.

Modo ilha

Uma faixa de 120×8 no topo da tela, estilo Dynamic Island: abre no hover, recolhe em 0,4 s e fixa com um clique.

O que vigiar

Por provedor: sessão de 5 h, semanal, mensal ou um limite do próprio plano, como o Fable (7d) do Claude.

Alerta por uso

Com icon_style = "alert" os números ficam verdes, âmbar e depois vermelhos, nos limites que você definir. O crítico respira devagar.

Barra de uso

Um traço de 2 px sob cada número mostra o quanto do limite já foi, e a cor muda com suavidade quando o estado muda.

    Instalação

    Dois comandos e a pílula aparece.

    O instalador cria um ambiente Python privado, baixa o PySide6 e registra o app no menu de aplicativos. Nada é instalado no Python do sistema.

    1

    Clone e instale

    Copia o app para ~/.local/share/vigia e cria o launcher em ~/.local/bin/vigia.

    $git clone https://github.com/stefanoferrao/vigia.git cd vigia && ./install.sh
    2

    Abra o VigIA

    Pelo terminal ou pelo atalho VigIA no menu de aplicativos.

    $vigia
    3

    Mostre e esconda com o atalho

    Ctrl+Alt+V mostra e esconde (e inicia, se não estiver rodando). Para trocar, edite hotkey no config.

    1

    Clone e rode o instalador

    No PowerShell, dentro da pasta clonada. Ele cria %LOCALAPPDATA%\vigia com o ambiente e os atalhos.

    PS>powershell -ExecutionPolicy Bypass -File .\install.ps1
    2

    Abra pelo menu Iniciar

    Procure por VigIA. O autostart usa a chave HKCU\...\Run e pode ser desligado no menu.

    0 de 0 passos copiados
    Dados das cotas: o VigIA lê os números do CLI ai-usagebar. Sem ele a pílula abre, mas fica sem números.
    Linux: precisa de libxcb-cursor0 (o instalador avisa e tenta resolver via apt, dnf ou pacman).
    Atalhos com Super: o sistema costuma capturá-los antes do app — por isso o padrão é Ctrl+Alt+V.
    O que vigiar

    Cada provedor mostra o limite que importa para você.

    O padrão é o maior uso. No menu, escolha a janela de cada provedor — a escolha fica salva e sobrevive a mudanças de nome no rótulo.

    57% Weekly (7d)

    Escolha acima para ver o que a pílula mostraria. No app, o mesmo acontece em O que vigiar.

    No dia a dia

    Teclado e terminal.

    ComandoO que faz
    vigiaabre a pílula (mostra a instância existente, se houver)
    vigia --showmostra, iniciando se preciso
    vigia --togglemostra/esconde — bom para atalho do sistema
    vigia --reloadrelê o config sem reiniciar
    vigia --quitencerra a instância
    vigia --versionimprime a versão
    Configuração

    Tudo em um TOML.

    O menu grava no arquivo; edições manuais são aplicadas com vigia --reload.

    Ver o config completo (Linux: ~/.config/vigia/vigia.toml · Windows: %APPDATA%\vigia\vigia.toml) 
    [overlay]
opacity = 0.82          # 0.40 a 1.00 — transparência só do fundo
size = "medium"         # small | medium | large
icon_style = "brand"    # brand | mono | alert
monitor = "primary"     # primary | secondary | all | "HDMI-A-0"
anchor = "top-right"    # top-left | top-center | top-right | ...
island = false          # true: encaixa no topo como faixa fina
always_on_top = true
show_system = false     # CPU / RAM / GPU
autostart = true
refresh_minutes = 5     # 1 a 60
max_providers = 4       # 1 a 8
hotkey = "<Control><Alt>v"
language = "auto"       # auto | pt | en | es | fr | de
theme = "vigia"         # vigia | auto | midnight | graphite | light | aurora | sunset | mono-hc
accent = ""             # "#rrggbb": troca a cor de realce do tema
bars = true             # barra fina de uso sob cada número
pulse = true            # valor crítico respira (icon_style = "alert")
alert_warn = 60
alert_critical = 80
hide_providers = ""     # "openai,gemini"
hide_system = ""        # "cpu,ram,gpu"

[overlay.metrics]       # qual limite cada provedor mostra
anthropic = "Weekly (7d)"
"opencode-go" = "Fable (7d)"

[overlay.positions]     # posição salva por monitor (o app cuida)
"HDMI-A-0" = [-40, 12]

[overlay.island_offsets] # deslocamento horizontal da ilha
"HDMI-A-0" = 220
